# Interactive Lab

복잡한 역사·관계·과정을 누구나 직관적으로 탐색할 수 있도록 만드는 인터랙티브 웹사이트입니다.

## 사이트

https://ejrgus.github.io/interactive-lab/

## 프로젝트 목표

- 글과 정적인 그림만으로 설명하기 어려운 내용을 시각적으로 표현합니다.
- 사용자가 직접 클릭하고 펼치고 이동하며 정보를 탐색할 수 있게 만듭니다.
- 기업의 역사부터 인체의 면역체계까지 다양한 주제를 하나의 사이트 안에서 다룹니다.

## 디자인 방향

Apple의 제품 페이지와 인터페이스에서 영감을 받은 간결하고 세련된 디자인을 지향합니다. Apple의 디자인을 그대로 복제하기보다는 다음 원칙을 참고합니다.

- 넉넉한 여백과 명확한 정보 구조
- 크고 읽기 쉬운 타이포그래피
- 콘텐츠에 집중할 수 있는 절제된 색상
- 모바일과 PC에서 모두 자연스럽게 보이는 반응형 화면
- 부드러운 스크롤과 전환 효과
- 사용자의 행동에 반응하는 세밀한 인터랙션

## 애니메이션 방향

애니메이션은 단순한 장식이 아니라 정보의 흐름과 관계를 이해하도록 돕는 데 사용합니다.

- 스크롤에 따라 콘텐츠가 자연스럽게 등장하는 효과
- 클릭하면 세부 정보가 펼쳐지고 다시 닫히는 구성
- 기업의 탄생·분리·합병 과정을 보여주는 타임라인 애니메이션
- 계열 관계를 따라 선과 카드가 연결되는 시각 효과
- 면역세포와 병원체의 움직임을 표현하는 시뮬레이션
- 과도한 움직임을 줄이고 사용자가 편안하게 볼 수 있는 속도 유지
- 운영체제의 '동작 줄이기' 설정을 존중하는 접근성 지원

## 예정된 콘텐츠

### 기업 역사와 지배구조

- 역대 대기업의 탄생 과정
- 시간순 계열분리와 회사명 변화
- 계열분리가 일어난 배경과 이유
- 이름은 공유하지만 서로 다른 회사가 된 사례
- 지배구조상 사실상 같은 기업으로 볼 수 있는 관계
- 과거에서 현재로 이어지는 좌우형 인터랙티브 타임라인

### 면역체계 시뮬레이션

- 병원체가 몸에 들어온 뒤 일어나는 과정
- 선천면역과 후천면역의 작동 방식
- 여러 면역세포의 역할과 상호작용
- 사용자의 선택에 따라 결과가 달라지는 인터랙티브 시뮬레이션

## 현재 상태

프로젝트의 기본 GitHub Pages 사이트를 개설했으며, 현재는 `TEST` 화면으로 배포 구조를 확인한 단계입니다. 앞으로 기능과 콘텐츠를 순차적으로 추가할 예정입니다.
