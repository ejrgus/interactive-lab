# Interactive Lab

복잡한 역사·관계·과정을 누구나 직관적으로 탐색할 수 있도록 만드는 인터랙티브 웹사이트입니다.

## 사이트

https://ejrgus.github.io/interactive-lab/

## 프로젝트 목표

- 글과 정적인 그림만으로 설명하기 어려운 내용을 시각적으로 표현합니다.
- 사용자가 직접 클릭하고 펼치고 이동하며 정보를 탐색할 수 있게 만듭니다.
- 기업의 역사부터 인체의 면역체계까지 다양한 주제를 하나의 사이트 안에서 다룹니다.

## 디자인 방향

Apple의 제품 페이지와 인터페이스에서 영감을 받은 간결하고 세련된 디자인을 지향합니다. Apple의 디자인을 그대로 복제하지 않고 넉넉한 여백, 명확한 정보 구조, 읽기 쉬운 타이포그래피, 절제된 움직임을 참고합니다.

애니메이션은 장식이 아니라 정보의 흐름과 관계를 이해하도록 돕는 데 사용합니다. 운영체제의 `동작 줄이기` 설정도 존중합니다.

## 폴더 구조

```text
├─ index.html                  # 홈
├─ companies/                 # 검색·사이드바·가로형 기업 계보
│  ├─ tree.css                # 테크트리 화면 스타일
│  └─ tree.js                 # 데이터 렌더링과 경로 강조
├─ sister-sites/              # 추천 사이트 목록 화면 (기존 주소 유지)
├─ immune/                    # 면역체계 시뮬레이션
├─ assets/                    # 공통 CSS와 JavaScript
├─ research/                  # 출처와 미확정 내용을 포함한 조사 노트
├─ data/                      # 화면이 사용하는 검증된 JSON 데이터
├─ CHANGELOG.md               # 완료된 주요 변경
└─ TODO.md                    # 앞으로 할 일
```

## 조사 자료와 화면 데이터

`research`의 Markdown에는 조사 과정, 출처, 충돌하는 설명과 미확정 내용을 기록합니다. `data`의 JSON에는 화면에 필요한 주요 사건과 계열사 관계를 옮기고, 출처 등급과 추가 확인 필요 여부를 함께 표시합니다. 원문의 문장과 출처 등급은 사실 검증을 대체하지 않습니다.

## 새 콘텐츠 추가 방법

1. `research`에 조사 문서를 만듭니다.
2. 출처가 확인된 사실을 `data`의 JSON으로 정리합니다.
3. 기능별 폴더에 HTML, CSS, JavaScript를 만듭니다.
4. 홈의 실험 배너에서 새 페이지를 연결하고, 공통 메뉴는 사이트 공통 목적지에만 사용합니다.
5. 완료한 변경은 `CHANGELOG.md`, 남은 작업은 `TODO.md`에 반영합니다.

## 예정된 콘텐츠

### 기업 역사와 지배구조

- 역대 대기업의 탄생 과정
- 시간순 계열분리와 회사명 변화
- 계열분리가 일어난 배경과 이유
- 이름은 공유하지만 서로 다른 회사가 된 사례
- 지배구조상 사실상 같은 기업으로 볼 수 있는 관계

### 면역체계 시뮬레이션

- 병원체가 몸에 들어온 뒤 일어나는 과정
- 선천면역과 후천면역의 작동 방식
- 여러 면역세포의 역할과 상호작용
- 사용자의 선택에 따라 결과가 달라지는 인터랙티브 시뮬레이션

## 배포

GitHub Pages가 `main` 브랜치의 루트 폴더를 배포합니다. `main`에 반영된 변경은 잠시 후 같은 사이트 주소에 자동으로 적용됩니다. 별도의 빌드 도구나 서버는 사용하지 않습니다.

## 현재 상태

로고 옆 상단 메뉴는 `홈`, `추천 사이트`로 구성됩니다. 홈을 아래로 스크롤하면 `기업 계보`와 `Peeker’s Advantage` 실험 배너가 차례로 나옵니다. 기업 계보는 탐색 화면으로 연결되고, Peeker’s Advantage는 아직 준비 중이라 이동 링크를 두지 않았습니다. `추천 사이트`는 외부 사이트로 바로 이동하지 않고 별도의 목록 화면을 엽니다. 현재는 PostHarness를 목록에 올렸으며, 카드의 `사이트 열기`에서 새 탭으로 이동합니다. 프로젝트 설명 문서인 이 README는 유지하지만 상단 메뉴에는 노출하지 않습니다.

기업 계보 화면은 PC에 최적화되어 있습니다. 해당 화면 상단에는 `범현대가·범삼성가·범LG가·범SK가·범롯데가` 5대 범가의 독립 버튼과 검색 버튼이 있고, 그 아래 스크롤 목록에는 `대우그룹·두산그룹·한화그룹·한진그룹`을 배치했습니다. 이 프로젝트에서 ‘범가’는 여러 독립 기업집단으로 갈라진 가문 묶음, ‘그룹’은 개별 기업집단을 표시하는 편집상 분류입니다. 대우그룹은 역사 속 집단이므로 현재 계열사를 하나로 묶지 않고 후신 기업의 현 소속을 보여줍니다. 선택은 `?family=lotte`, `?family=daewoo`, `?family=hanjin` 같은 주소에 남아 같은 화면을 바로 공유할 수 있습니다. 계보 화면의 검색 버튼을 누르면 통합 탐색창에서 가문·그룹·기업·옛 이름·현재 계열사·이탈 기업을 찾을 수 있습니다.

`전체 계보`, `연혁`, `현재 그룹`, `이탈·소멸 기업`, `전체 조사 원문` 보기를 전환하면 계보 밖의 세부 자료까지 확인할 수 있습니다. 제공된 조사 원고는 `research/*-family-complete.md`에 보존합니다. 새 그룹의 원문 제목에 ‘범’ 표현이 남아 있어도 사이트 메뉴에는 그룹으로 표시합니다. 화면에는 정부·공시(A), 기업 공식자료(B), 언론(C), 위키 참고자료(D)의 출처 등급과 미확인 상태를 표시합니다. 이는 역사 탐색용 아카이브이며 모든 법인의 실시간 지분율을 망라한 법률·투자 자료는 아닙니다.
